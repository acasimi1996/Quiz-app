# Kviz Aplikacija (JavaScript Quiz App)

Interaktivna web aplikacija sa pitanjima višestrukog izbora, napravljena korišćenjem čistog (Vanilla) JavaScript-a, HTML-a i CSS-a.

## Opis Projekta
Kviz aplikacija vodi korisnika kroz niz pažljivo odabranih pitanja iz programiranja. Prati napredak, proverava tačnost odgovora u realnom vremenu (bojenjem dugmadi u zeleno/crveno), računa ukupan broj poena i omogućava ponovno igranje na kraju.

## Korišćene Tehnologije
* **HTML5** (Struktura)
* **CSS3** (Dizajn interfejsa, dinamičke klase, animacije)
* **JavaScript (ES6+)** (Upravljanje stanjem, manipulacija DOM-om, rad sa nizovima i objektima, funkcije)

## Šta sam naučio/la i vežbao/la ovim projektom?
* Upravljanje stanjem aplikacije (`currentQuestionIndex` i `score`).
* Dinamičko kreiranje i brisanje DOM elemenata petljama (`forEach`).
* Kontrolu toka interakcije korisnika (onemogućavanje dugmadi nakon izbora, uslovni prikazi ekrana).
* Logiku prelaza između pitanja i prikazivanja konačnog rezultata.

## Kako da pokreneš projekat lokalno?
1. Preuzmi ili kloniraj repozitorijum.
2. Otvori fajl `index.html` u svom web pretraživaču.
